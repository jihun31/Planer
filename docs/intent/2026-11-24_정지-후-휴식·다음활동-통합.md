# 정지 후 휴식 연결과 다음 활동 선택 통합

2026-11-24 인터뷰로 확정한 의도.

- **Outcome:** 기록 타이머를 정지하면 창 하나에서 "휴식 시작 (N분)", 다음 활동 배지, 종료 중 하나를 고른다. 휴식 확인 창(`FlowRestConfirm`)은 다음 활동 창(`TimerSwitchDialog`)에 흡수한다.
- **User:** Planner 사용자 본인. 지금은 휴식 창에서 건너뛰기를 누르면 다음 활동을 고를 수 없다.
- **Why now:** 두 창이 서로 배타적이다(`TimerBlock.jsx`의 `!restMinutes && switchEnabled`). 휴식 연결을 켜 두면 다음 활동 창이 아예 뜨지 않는다.
- **Success:**
  - 두 설정 중 하나라도 켜져 있으면 정지할 때 통합 창이 뜬다.
  - 휴식 연결이 켜져 있으면 휴식 버튼이, 다음 활동 창 설정이 켜져 있으면 활동 배지가 보인다.
  - 휴식 버튼은 창 아래쪽 버튼 줄에 둔다. 종료 버튼은 왼쪽, "휴식 시작 (N분)"은 오른쪽이다. 휴식 버튼은 주 버튼 모양이고 기본 포커스를 받는다.
  - 배지 목록의 기존 "휴식" 활동 배지(시간을 정하지 않은 일반 휴식)는 그대로 두고, 휴식 버튼과 모양·위치로 구분한다.
  - 휴식이 끝나면 지금처럼 원래 활동으로 돌아간다(`returnActivityId`).
  - "작업 종료 시 휴식 연결"(`planer:flow-rest`)의 기본값을 끔으로 바꾼다. 이 설정을 직접 바꾼 적이 없는 기존 사용자도 꺼진 상태가 된다.
- **Constraint:** 설정은 두 개 그대로 둔다. 휴식 버튼은 기록 타이머를 정지할 때만 나오고, 통제 타이머를 정지하면 활동 배지만 나온다.
- **Out of scope:**
  - 휴식이 끝날 때 다음 활동 창을 다시 띄우는 것
  - 두 설정을 하나로 합치는 것
  - 휴식 길이 계산(20% 비율)을 바꾸는 것
