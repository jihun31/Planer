# 의도: 표시 이름 Planer → Planner 철자 수정 (2026-11-23 확정)

- **Outcome**: 사용자 눈에 보이는 이름만 Planner로 바꾼다 — 창 제목, 바로가기·시작 메뉴 이름, 화면 문구, 설치 프로그램 파일명(`Planer-Setup-*.exe`), 릴리스 제목, 문서, 봇 안내 문구.
- **User**: 앱을 쓰는 본인과 봇 사용자.
- **Why now**: Planer는 철자가 틀린 이름이다(영어로는 Planner가 맞다).
- **Success**: 앱·설치 프로그램·문서·봇에서 사용자에게 보이는 "Planer"가 남지 않는다. 기존 설치본은 로그인과 설정을 그대로 유지한 채 자동 업데이트로 이어진다. `npm run test:affected`와 `npm run check:version`이 통과하고 `npm run install:local`로 로컬 설치본에 반영된다.
- **Constraint**: 기존 설치본의 데이터 경로(userData)와 업데이트 연속성을 깨면 안 된다.
  - 참고: `productName`을 바꾸면 설치 경로와 userData 경로가 바뀌므로, 창 제목·바로가기 이름은 `productName` 대신 별도 설정(예: `BrowserWindow` title, NSIS `shortcutName`)으로 바꿔야 한다.
  - 참고: 설치 프로그램 파일명은 자동 업데이트가 `latest.yml`을 따라가므로 바꿔도 된다. `release.yml`의 파일명 검사도 같이 고친다.
- **Out of scope**:
  - 내부 식별자: `appId`(`com.planer.app`), `productName`, `package.json`의 `name`, 설치 폴더(`AppData\Local\Programs\Planer`), 앱 데이터 폴더, localStorage 키(`planer:*`), 에뮬레이터 프로젝트 ID(`demo-planer-security`)
  - Firebase 프로젝트 ID(`planer-f8cb7`)
  - GitHub 저장소 이름(`jihun31/Planer`)
  - 저장소 폴더와 문서 안의 실제 경로 표기(`C:\Users\baek\Projects\Planer` 등)
  - Claude 메모리 폴더
