# 메모 폴더 중첩 (폴더 안에 폴더)

확정일: 2026-11-24 (사용자 "예"로 확정)

- **Outcome:** 메모 화면 왼쪽 폴더 칸을 접고 펴는 트리로 바꿔 폴더 안에 폴더를 최대 3단계까지 넣는다. 다른 폴더 위 가운데로 끌어다 놓으면 그 안으로 들어가고, 위·아래로 놓으면 순서가 바뀐다. 폴더마다 펼침/접힘 상태를 기억한다.
- **User:** 데스크톱에서 Planner 메모를 쓰는 사용자 본인.
- **Why now:** 최상위 폴더가 많아져 목록이 길고 찾기 어렵다. "전공" 같은 묶음 아래로 넣고 평소에는 접어 두고 싶다.
- **Success:**
  - 3단계까지 폴더를 만들고 끌어 넣을 수 있다. 4단계가 되는 이동은 막는다.
  - 폴더를 자기 하위 폴더 안으로 넣는 것도 막는다.
  - 폴더를 누르면 그 폴더에 직접 든 메모만 보이고, 개수도 같은 기준으로 센다.
  - 폴더를 지우면 "하위 폴더 N개, 메모 M개가 함께 영구 삭제됩니다" 확인 창이 뜨고, 승인하면 모두 지운다(휴지통이 없으므로 되돌릴 수 없음을 확인 창에 밝힌다).
  - 하위 폴더가 없는 지금 구조의 폴더도 같은 방식으로 바뀐다. 지금은 메모를 "폴더 없음"으로 옮기지만(`deleteNoteFolder`), 앞으로는 확인 후 함께 지운다.
- **Constraint:**
  - 폴더 문서에 `parentId`를 추가하고 Firestore 규칙과 규칙 테스트를 함께 고친다.
  - 기존 폴더는 `parentId`가 없어도 최상위 폴더로 읽혀야 한다.
  - 지금의 세 칸 화면 구조(폴더 | 메모 목록 | 편집기)는 유지한다.
- **Out of scope:**
  - 좁은 화면·모바일 전용 화면
  - 상위 폴더에서 하위 폴더 메모까지 모아 보기
  - 휴지통·삭제 되돌리기
  - 4단계 이상의 폴더
  - 열 보기(Finder 방식)나 한 단계씩 들어가는 방식

## 참고한 현재 코드

- 저장: `src/features/notes/noteLibraryService.js` (`deleteNoteFolder`, `reorderNoteFolders`)
