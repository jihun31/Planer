# Planer 1.0.5

## 주요 변경

- 메모장에 체크리스트를 추가했습니다. `/체크리스트`, `/todo` 또는 줄 앞의 `[]`와 Space로 만들 수 있습니다.
- 체크리스트의 연속 입력, 완료 표시, 여러 항목 삭제 후 재입력, 빈 항목의 Backspace 삭제와 커서 위치를 수정했습니다.
- 글자 서식 메뉴와 `Ctrl+Shift+S`로 취소선을 적용·해제할 수 있습니다.
- 메모의 토글, 목록 들여쓰기, 텍스트 이동, 링크 미리보기와 폴더별 조회를 개선했습니다.
- ‘오늘 할 일’의 계획표에서 날짜별 계획과 요일별 반복 계획을 등록할 수 있습니다.
- 계획과 다른 활동을 기록하면 해당 계획의 이름과 테두리를 숨기며, 같은 활동이 연속되면 하나로 이어서 표시합니다.
- 계획표 아래의 관리 토글과 구분선을 제거했습니다.

## 다운로드

- Windows 64비트 설치파일: **Planer.Setup.1.0.5.exe**
- 같은 버전의 소스코드: **Planer-1.0.5-source.zip** 또는 GitHub의 Source code 압축파일

기존 버전이 설치되어 있으면 새 설치파일을 실행해 업데이트할 수 있습니다.

체크리스트에서 Enter는 다음 항목을 만들고, 빈 항목에서 Enter 또는 Backspace는 일반 문장으로 돌아갑니다. Tab과 Shift+Tab으로 들여쓰기를 조절합니다.

계획표의 서버 권한 설정이 아직 반영되지 않은 환경에서는 저장소의 `DAY_PLANS_SETUP.md`를 참고하세요. 이 릴리스 업로드는 Firebase 서버 규칙을 변경하지 않습니다.
